# Portfolio documentation site

Published at https://novolis-platform.github.io/.github/ from [`.github/workflows/pages.yml`](../.github/workflows/pages.yml).

## What you get

| Surface | Behavior |
|---------|----------|
| Catalog (`index.html`) | One card per library with **Docs** + **Source** |
| Docs button | Opens `{repo}/index.html` — that repo's `docs/README.md` (or a generated overview) |
| Sidebar | Autogenerated from the `docs/` folder: Required guides + Browse tree |
| Pages | `{repo}/getting-started.html`, nested folders preserved |

## Pipeline

1. **Sparse collect** — [`scripts/Collect-OrgDocsSparse.ps1`](../scripts/Collect-OrgDocsSparse.ps1) clones every public org repo with `git clone --filter=blob:none --sparse` and materializes only `docs/`.
2. **Generate site** — `novolis-docs site` (`Novolis.Tools.Docs.Cli`) renders HTML via **Novolis.Markup**.

```powershell
pwsh -File d:\novolis\.github\scripts\Build-PortfolioPages.ps1
```

Local iteration against a sibling CLI:

```powershell
pwsh -File d:\novolis\.github\scripts\Collect-OrgDocsSparse.ps1 -OutDir d:\novolis\.github\corpus
dotnet run --project d:\novolis\novolis-tools\src\Novolis.Tools.Docs.Cli -c Release -- site `
  --corpus d:\novolis\.github\corpus `
  --out d:\novolis\.github\_site `
  --assets d:\novolis\.github\site\assets `
  --brand d:\novolis\.github\brand
```

## Required docs links

Sidebar **Required** section always lists:

1. Overview (`docs/README.md` → `{repo}/index.html`)
2. Getting started
3. Design
4. Release

Missing required files show as muted placeholders. Repos without `docs/README.md` get a generated overview index that links the rest of the tree.
