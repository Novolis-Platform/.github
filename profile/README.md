# Novolis

**A quiet home for the work.**

Platform-oriented .NET libraries with progressive complexity and no forced
mega-engine. Physics and simulation stay headless; Raylib, Avalonia, and MAUI
compose at the edges; products install from packages and ship deliberately.

<p align="center">
  <code>Math → Physics → Simulation → Gaming → Avalonia → Apps</code><br/>
  <sub>MAUI is an orthogonal product island; host applications choose their UI edge.</sub>
</p>

## Get started

**GitHub Packages** (continuous builds, `2026.1.*`):

```text
https://nuget.pkg.github.com/Novolis-Platform/index.json
```

```powershell
# once per machine (writes user NuGet.config credentials)
pwsh -File ../novolis-governance/scripts/configure-gpr-user-nuget.ps1

dotnet add package Novolis.Raylib
dotnet add package Novolis.Audio
dotnet add package Novolis.Messaging.Channels
```

## Build, package & release

| Stage | Trigger | What happens |
|-------|---------|--------------|
| Build | PR to `main` (`pull-request.yml`) | Restore, build, test — no publish |
| Package | Push to `main` (`merge.yml`) | Pack `YEAR.MAJOR.MINOR.{run}` → [GitHub Packages](https://github.com/orgs/Novolis-Platform/packages) |
| Release | GitHub Release published (`release.yml`) | Promote packages to [nuget.org](https://www.nuget.org/); publish product installers, APKs, and bundles as release assets |

Versions are four-part numeric only (`2026.1.1.351`) — see [nuget-versioning.md](https://github.com/Novolis-Platform/.github/blob/main/docs/nuget-versioning.md). Product hosts (`novolis-apps`) ship installers and Android bundles through deliberate release workflows instead of nuget.org.

## About

**Modern .NET for realtime systems, graphics, games, and studios.**

Novolis is a quiet home for the work: platform-oriented rather than
product-locked, pleasant in both OSS and enterprise conversations, and built
with progressive complexity, composable architecture, modern .NET patterns,
and low ceremony. There is no forced mega-engine or mandatory ECS.

The platform map is intentional: **Math → Physics → Simulation → Gaming →
Avalonia/MAUI → products**. Headless layers remain reusable; UI libraries own
the shared chrome; executable hosts compose the pieces at the edge.
